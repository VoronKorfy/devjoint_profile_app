# DevJoint Profile App

A multi-screen Flutter application created for the DevJoint portal. The app includes an onboarding screen, a profile page with user statistics, custom input fields for editing profile information, and widget tests.

## Features

- Onboarding screen with page swipe and Skip button.
- Profile screen with user stats and action buttons.
- Edit Profile screen with input fields and character limits.
- Settings screen for app options.
- Automated tests for widget navigation and onboarding logic.

---

## Packages Used

- flutter: Core SDK for building the user interface.
- cupertino_icons: Additional iOS-style icons.
- flutter_test: Testing library for running widget tests.

---

## Installation Steps

Follow these steps to run the project on your local machine:

1. Clone the repository:
   git clone https://github.com/VoronKorfy/devjoint_profile_app.git

2. Open the project folder:
   cd devjoint_profile_app

3. Install project dependencies:
   flutter pub get

4. Connect your device or emulator and run the app:
   flutter run

---

## Running Tests

To run all automated widget tests, execute this command in your terminal:

flutter run test
